01撞库：一处泄露，处处失守

攻击者很少正面攻破大公司的系统。更省事的办法是：找一个防护薄弱的小网站，把它的用户数据库整个拿走（俗称“拖库”），得到一份邮箱 / 手机号 + 密码的清单，然后拿这份清单去各大网站自动批量登录。这就是撞库（credential stuffing）。

只要你在那个小网站用的密码，和你的邮箱、支付、社交账号是同一个，攻击者就不需要破解任何东西，直接登进去。

这不是假设。2011 年底，国内一家知名开发者社区被曝以明文存储了约 600 万用户的密码，随后多个网站的数据相继流出；2014 年，12306 也出现过一批用户信息外泄，官方说法是被他人用其他网站泄露的账号密码撞库所得。今天，网上流传的密码汇编动辄几十亿条，撞库早已是全自动、低成本的生意。

记住一句话：你所有账号的安全程度，等于你用了同一个密码的那些网站里，最差的那一个。

02小平台为什么更危险

大平台有专门的安全团队、异常登录检测和两步验证；很多小网站、小程序、老论坛则不然。你注册时根本看不出它是怎么保管你的密码的。

小平台常见的短板：

短板后果
明文或用 MD5 之类的快速哈希存密码一旦拖库，大部分密码很快被还原
不限制登录次数，没有异常登录提醒撞库和暴力猜测畅通无阻，你也毫不知情
不支持两步验证密码就是唯一一道门
出了事不公告、不通知你继续在别处用着已经泄露的密码
网站停运、被转手数据库去向不明，多年后仍可能流出

你没法改变别人怎么存你的密码，能做的只有一件事：假设每个网站迟早会泄露，并保证它泄露时只丢它自己。

两点容易被误解：

“看起来复杂”不等于随机。Zhang1990! 有大写、数字、符号，但它是“名字 + 年份 + 感叹号”，破解工具专门有这类规则，几秒就能试到。真正安全的密码是机器随机生成的，你记不住，也不需要记住。

强密码救不了重复使用。撞库时攻击者拿到的是原文（明文网站直接给出，或者已被还原），再长的密码，用在第二个网站上就和 123456 一样脆弱。

04邮箱是所有账号的总钥匙

几乎每个网站都有“忘记密码”，而重置链接会发到你的邮箱（或者短信发到你的手机号）。谁控制了你的邮箱，谁就能重置你几乎所有账号的密码。

05两步验证与钓鱼

两步验证：密码泄露后的最后一道门

开了两步验证（2FA），登录时除了密码还要第二样东西。即使密码被撞库拿到，攻击者也卡在第二步。但不同方式强度不同：

方式强度说明
短信验证码有，但最弱可能遭遇 SIM 卡劫持、短信拦截；比没有强得多
验证器 App（TOTP，6 位动态码）较强码在本机生成，不经运营商；仍可能被钓鱼网站实时转发
通行密钥（Passkey）/ 硬件安全密钥最强和网站域名绑定，钓鱼网站拿不到；也没有密码可以泄露

小平台不支持两步验证的时候，独立的随机密码就是你唯一能依靠的东西。

钓鱼：人会看错网址，密码管理器不会

钓鱼网站可以把页面做得和真的一模一样，只在网址上差一个字符。人很难每次都注意到，而密码管理器是按域名匹配的：域名不对，它就不会填。“这次怎么没有自动填充？”本身就是一个警报。

06现在就能做的五件事

  1. 查一查自己有没有被泄露在 haveibeenpwned.com 输入常用邮箱，看看它出现在哪些泄露事件里。
  2. 先救主邮箱给主邮箱换一个独一无二的强密码，开启两步验证（优先验证器 App 或通行密钥），保存好恢复码。
  3. 用密码管理器，每个网站一个随机密码你只需要记住一个主密码，其余全部交给它生成和填充。从最重要的账号开始换：邮箱、支付、云盘、社交、工作。
  4. 能开两步验证的地方都开尤其是涉及钱、照片、工作资料的账号。支持通行密钥的网站，直接用通行密钥。
  5. 不用的账号注销掉注册过就忘了的网站，是最可能悄悄泄露的那一个。

主密码怎么设？用 5～6 个随机挑选的词拼成一句（例如“台灯 涨潮 橘子 跑道 邮票”），够长、好记、难猜。不要用歌词、名言、生日。它是唯一需要你记住的密码，也是唯一不能和任何别的密码相同的密码。

07为什么推荐本地优先的密码管理器

密码管理器把所有密码集中到一处，所以“这一处”放在哪里很重要。

云端密码管理器并非不安全，主流产品都会在本地加密后再上传。但它们有一个绕不开的结构问题：所有用户的加密库集中在同一个地方，对攻击者来说回报极高。2022 年，一家知名云端密码管理器就披露过客户的加密密码库备份被攻击者复制；此后安全研究人员把多起加密货币被盗事件和这次泄露联系起来，主密码不够强的用户首当其冲。库一旦被带走，攻击者就可以离线慢慢猜主密码，不受任何次数限制。

本地优先的好处

  • 密码库只在你的设备上解密，没有一个“存着所有人密码”的服务器可以被攻破
  • 不依赖服务商在线：断网能用，公司倒闭、涨价、停服也不影响你
  • 用开放格式（如 KDBX），随时换别的软件打开，不被锁定
  • 同步走你自己选的网盘或 WebDAV，上面只有一个加密文件

需要你自己负责的

  • 主密码忘了就找不回，没有人能帮你重置
  • 要定期备份那个加密文件（放网盘本身就是一份）
  • 设备本身要可靠：系统更新、锁屏、别装来路不明的软件
  • 主密码仍然要够强：文件被人拿到时，它是唯一的防线

说到底，密码管理器解决的是“每个网站一个随机密码”这件人做不到的事；本地优先解决的是“这些密码最终归谁管”。把钥匙串放在自己口袋里，而不是寄存在一个所有人都寄存的柜台。

如果你想试试本地优先的密码管理器：Vaultlet 是一个开源项目，密码库是标准 KDBX 4 文件，支持桌面端、浏览器插件、Android 和 iOS，能从 Chrome、Firefox、Safari 和 Bitwarden 导入。KeePassXC、Strongbox 等同样基于 KDBX 的软件也都是不错的选择。
